# Virtual Art Museum
Virtual Art Museum es un sitio web que permite explorar una colección de obras de arte.

## Funcionalidades
- Pagina inicio   : con enlaces para acceder y registrarse.
- Pagina login    : formulari de acceder.
- Pagina register : 
    * P1 : Selección del tipo de cuenta entre visitante y artista.
    * P2 : Formulari de registrar
- Pagina navigador : Galería con enlaces para abrir las imágenes de las obras.
- Diseño adaptable a pantallas pequeñas y navegación con el teclado.

## Tecnologías
- HTML
- CSS
- JavaScript
  
## Cómo abrir el proyecto
Abre el archivo `Home.html` en el navegador.

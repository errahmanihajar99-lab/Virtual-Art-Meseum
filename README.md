# Virtual Art Museum
Virtual Art Museum es un sitio web que permite explorar una colección de obras de arte mias.

## Funcionalidades
- Pagina inicio   : con enlaces para acceder y registrarse.
- Pagina login    : formulari de acceder.
- Pagina register : Formulari de registrar
- Pagina navigador: Galería con enlaces para abrir las imágenes de las obras.
- Diseño adaptable a pantallas pequeñas y navegación con el teclado.

## Tecnologías
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- PDO MySQL
- Composer
